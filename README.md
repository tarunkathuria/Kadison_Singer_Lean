# Kadison_Singer_Lean
This repository contains a lean proof of the Weaver's discrepancy/Kadison Singer conjecture (independent of the Marcus Spielman Srivastava proof) conjecture. The proof is based on random walks and operator valued free probability ideas. While the theorem formulated in this repo only leads to an existence argument, one can actually show that the algorithm can be executed in poly time as well leading to the only known algorithmic proof of the Weaver's discrepancy conjecture. Based on a suggestion by a friend, inspired by the emerging trend of time-stamping proofs via Lean -see for instance https://blog.computationalcomplexity.org/2026/09/navier-stokes-and-lean.html - before one has had time to write up the proof clearly), I decided to use GPT to formalize the proof in Lean and this is the result. This repo is private for now but will eventually be made public.
